# Third-party notices

The three prepared paper assets are generated by Scrunch's own
`tools/scrunchfx-assets/author.mjs`. No Codrops geometry, motion, sample designs,
JavaScript application code or physics engine is shipped. The original Codrops
asset was retired in this milestone; its source-specific notice is retained in
Git history with the code and asset to which it applied.

Direct3D11, DXGI, DirectComposition and shader-compiler bindings use
[Vortice.Windows](https://github.com/amerkoleci/Vortice.Windows) 3.8.3, MIT,
copyright Amer Koleci and Contributors. See `Vortice-LICENSE.txt`.
Vortice.Direct2D1 is a transitive binding dependency of DirectComposition;
ScrunchFX does not instantiate a Direct2D renderer.
