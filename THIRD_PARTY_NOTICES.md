Release builds include `DEPENDENCY_NOTICES.txt`, assembled from the **restored
package versions** and runtime packs. It contains full package licence texts,
copyright notices and third-party notices, including transitive native libraries.
The package lockfile records dependency hashes. Build-only Windows SDK / WinApp
tools are not redistributed in the app.

Segoe UI and emoji/script fallbacks come from Windows and are not bundled.
Font provenance and hashes are recorded in `src/Scrunch/Assets/Fonts/NOTICE.txt`.

ScrunchFX's three prepared `.nfx` files are generated by
`tools/scrunchfx-assets/author.mjs`. No Codrops/Houdini geometry, motion, application
code or physics engine remains in the current source tree or production payload.
The retired asset's attribution stays with its original revisions in Git history.
The binary bake format is defined solely by that generator.

Inno Setup is a build tool; its generated setup/uninstaller retains the vendor's
embedded notices. Compiler version and download hash are pinned in
`tools/get-inno.ps1`. [Inno Setup licensing](https://jrsoftware.org/isinfo.php).
