# Scrunch 0.1.0

Initial Windows x64 release: independent local desktop notes, tray access,
Ctrl+Alt+N, recoverable crumple/discard and optional start at sign-in.

- `Scrunch-0.1.0-Setup.exe`: per-user installer; no administrator access required.
- `Scrunch-0.1.0-win-x64.zip`: extract completely and run Scrunch.exe.
- `SHA256SUMS.txt`: SHA-256 checksums for both artifacts.

The app includes its .NET and Windows App SDK runtime dependencies. Binaries are
unsigned, so Windows may show an unknown-publisher or SmartScreen warning.

Notes and preferences are preserved through upgrades and uninstall. Existing legacy
notes migrate by copy; originals remain intact. No accounts, cloud or telemetry.
MIT project licence; bundled dependencies retain their own licences.

See the repository's release verification report for the tested Windows version,
exact artifact evidence and known hardware limitations.
